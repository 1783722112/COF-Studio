装不上依赖？照这个来
建模只需要三个小包，几十秒装完；优化要 torch，比较大。 两个分开装更省事（torch 环境不用装 rdkit）。
:: 建模环境 / build env python -m pip install numpy ase rdkit :: 优化环境（另开一个 venv 更好）/ opt env (separate venv preferred) python -m pip install numpy ase torch mace-torch torch-dftd matplotlib scipy
QCOF 权重 2.6 MB 会自动下载；MACE-MP-0 约 42 MB、 MACE-OFF23 系列 7~53 MB，需要时在界面上勾「允许联网下载」。
