# COF Studio

三维/二维 COF 结构建模 + 势函数优化的本地工作台。填两个单体 SMILES，
出结构，再一键丢给 MACE 势弛豫，导出优化后的 CIF。

界面在浏览器里跑（`http://127.0.0.1:8770`），三维预览是自己写的 canvas
投影，不联网也能用。Web 部分只用 Python 标准库，不用装 Flask / Dash。

界面**中英双语**：右上角 `中文 / EN` 一点即切（设置弹层里也有一组，
两处联动），选择会写进 `config.json` —— 换端口、重开程序都还是这个语言；
也可以用 `?lang=en` 直接进英文界面。注意引擎自己打印的日志（控制台里那些
"单层厚度 / 骨架 0.000 Å"）仍是中文，那是 Python 脚本的输出，不影响操作。

启动后默认落在 **2D 建模**页签；`?tab=3d` / `?tab=opt` 可以直连其它页签。

## 快速开始

### 情形零：拿到的是「桌面版」文件夹（推荐）

里面只有一个 **`COFStudio.exe`** 和一个 `_internal` 文件夹。
双击 exe 即可 —— 不弹黑窗口，直接开一个独立的应用窗口（Edge/Chrome 的应用模式，
没有地址栏）。内置 Python 与 numpy / ase / scipy / rdkit，对方什么都不用装。

> 注意：`_internal` 必须和 exe 待在一起，拷贝时整个文件夹一起拷。
> 桌面版**不含**势函数优化（torch + 权重约 2 GB）；要跑优化，
> 在 exe 旁边的 `config.json` 里把 `py_opt` 指向本机装了 torch/mace 的 python.exe。

**改了代码要重新出包**：双击 `build_exe.bat`（复用 `.build_env`，约半分钟），
产物在 `桌面/COF Studio/`；再跑 `python pack_app.py` 压成可分享的 zip。
exe 里存的是 `ui.html`、`engines/` 的**副本**，改了源码不重新打包不会生效。

### 情形一：拿到的是「便携版」压缩包（什么都没装）

解压后**不要挑文件**，整个文件夹一起解出来，然后双击 **`run.bat`**。
浏览器会自动打开，不需要装 Python，也不需要联网。

> 判断是不是便携版：文件夹里有一个 `runtime` 子文件夹（约 400 MB）。
> 如果只解压出几个文件、`runtime` 没带上，就会出现「浏览器无法访问此网站」
> ——因为服务根本没起来。重新完整解压即可。

### 情形二：拿到的是源码（只有几个 .py）

#### Windows

1. 双击 **`install.bat`** —— 建虚拟环境、装依赖（问你要不要装优化环境时，
   不装也能建模）
2. 双击 **`run.bat`** —— 浏览器自动打开界面

#### macOS / Linux

```bash
./install.sh
./run.sh
```

#### 手动

```bash
python cof_studio.py               # 默认 127.0.0.1:8770
python cof_studio.py --port 9000 --open
```

## 为什么别人「打不开」

`ui.html` 只是一张皮，**必须靠 `run.bat` 起的本地服务**才能工作。
三个最常见的错法：

| 错法 | 现象 | 正确做法 |
|---|---|---|
| 直接双击 `ui.html` | 界面能出来，一点按钮就报错（现在会弹红条提示） | 双击 `run.bat` |
| 没解压，在压缩包里双击 | 解压到临时目录，产物散落、下次找不到 | 先完整解压 |
| 服务没起来就敲网址 | 浏览器「无法访问此网站」 | 等黑窗口出现「界面地址」再访问 |

服务默认只监听 `127.0.0.1`，**同一个局域网的其他电脑访问不到**。要让同事
用浏览器连你的机器，加 `--host 0.0.0.0` 启动，再用 `ipconfig` 查你自己的
IPv4 地址，让对方访问 `http://你的IP:8770`（可能需要在防火墙放行）。

## 三步流程

### 1 · 建模

左侧填两个单体，选拓扑和连接方式，点「开始建模」。

| 页签 | 用途 | 引擎 |
|---|---|---|
| **3D 建模** | 三维骨架（ctn / dia 拓扑） | `engines/build_cof_3d.py` |
| **2D 建模** | 二维单层（hcb / sql） | `engines/cof_builder.py` |

两个单体的 SMILES **顺序无所谓**，脚本自己判断谁是出醛、谁是出胺。
点「常用体系」里的预设可以直接填好一整组参数：2D 只留了 **LZU-1** 和
**TAPB-PDA**，3D 留了 **BF-COF-1**（都是能一次建通的体系）。

建完的提示框里直接有 **「下载 CIF」**，不用去 `work/` 文件夹里翻。

3D 的晶胞边长 `a` 默认「自动推算」：按单体臂长和连接键长反推，
BF-COF-1 算出来 24.677 Å，文献值 24.798 Å（差 0.5%）。

#### 层间堆叠与 XRD（2D 页签，1.3.0 起）

2D 建模默认把单层复制成 **AA 对齐的双层**（层数 1–6 可调），三种堆积方式：

| 方式 | 含义 |
|---|---|
| **AA 对齐**（默认） | 层层完全对齐（eclipsed） |
| **AB 交错** | 隔层错开 (dx, dy)，默认半格 (0.5, 0.5)，可改 |
| **自由移动** | 每层比上一层再多滑 (dx, dy)，ABC 型连续滑移 |

层间距默认 3.60 Å（`--c`），偏移量用**分数坐标**，不依赖晶胞形状。
堆叠产物单独存一份：`<名字>_AA2L.cif` 这种，单层文件也保留（送去优化用单层）。

建完点「**XRD 图谱**」直接出模拟粉末衍射：结构因子 + Cromer-Mann 散射因子 +
LP 因子 + 伪 Voigt 峰形（宽度由晶粒尺寸决定，Scherrer）。
**2θ 范围、步长、靶材（Cu/Mo/Co Kα）、晶粒尺寸、温度因子 B 都能在弹层里改，改完点「重新计算」**，
曲线和峰表（2θ / d / hkl / 多重度 m / I）实时刷新，可下载 CSV 数据和 SVG 图。

1.3.2 起引擎会自动处理三种常见「不准」：

- **真空层胞 / 超胞**：单层或优化模型沿 c 带十几到几十 Å 真空时，倒格矢 1/c
  被人为拉长，(00l) 跑到低角、(hk0) 强峰被压掉。典型症状：最强峰 3.15°，
  而 d = 28.0 Å —— 正好等于 c，是个假峰。1.3.3 起引擎会先按 z 切层，
  把 N 层超胞约化到真实层间周期（AA 留 1 层、AB 留 2 层，AB 的两层不等价，
  周期本来就是 2 层），单层 + 真空则按 AA 堆叠（层间距 d，默认 3.60 Å）压回；
  三维骨架（c 方向有成键）一律不动。弹窗有黄色提示，不想压就取消勾选。
- **hkl 标注**：同一晶面族统一选好读的代表，六方的 (100) 不会再显示成
  (0 -1 0)。
- **峰表强度**：I 按整个简并晶面族求和（原实现只列族里最强一条，
  (220)/(311) 这类高多重度峰被低估 2–3 倍），并新增多重度 m 列，
  与画出的曲线高度一致。
- **低角截断**：最强峰落在 2θ 起点以下（大孔径 COF 常见）时自动把
  起点下探并提示。

校验：Si / NaCl 峰位与标准卡片一致；LZU-1、TAPB-PDA 的峰位与 pymatgen
独立实现逐条吻合（强度差 < 10%，来自温度因子取值）。

注意一个物理事实：AA 和 AB 的**面内** (hk0) 峰本来就应该一样
（平移不改变投影），差别出现在带 l 的 (hkl) 峰上——比如 AA 双层的奇数 l
严格消光、AB 不消光。想看差异把 2θ 范围拉到 20–30°。

拓扑和连接数必须对得上：

| 拓扑 | 需要的单体 | 典型体系 |
|---|---|---|
| `ctn` | 4 连接 + 3 连接 | BF-COF-1（TAA + 均苯三甲醛） |
| `dia` | 4 连接 + 2 连接 | COF-300（四苯甲烷四胺 + 对苯二甲醛） |

对不上时脚本会直接告诉你「可选的拓扑是什么」。

### 2 · 看

右侧画布可以拖拽旋转、滚轮缩放、双击复位。顶上有四个按钮：

- **H** —— 显示/隐藏氢原子。**默认是显示的**，点一下才隐藏（三维框架原子多，想看骨架时再收起来）。顶上指标条里的 `H 240` 就是胞内氢原子数，藏起来后会变成 `H 240 已隐藏`，不会误以为结构缺氢。
- **立方体** —— 显示/隐藏晶胞框
- **循环箭头** —— 自动旋转
- **相机** —— 存成 PNG

层状结构会自动俯视 + 2×2 平铺，不然只画一个胞只看得到半个孔。

左上角的标签是实时体检结果：原子数、化学式、晶胞参数、密度、
最短原子间距、连接键数和键长。

### 3 · 优化

建模成功后点「送去优化 →」，参数会自动带过去。也可以直接在「势函数优化」
页签里从下拉框挑 `work/` 里已有的结构。

| 势函数 | 适用 | 说明 |
|---|---|---|
| **MACE-MP-0 + D3** | 三维框架、多层 | 有层间色散，通用材料势。**3D 框架首选** |
| **QCOF** | 二维单层 | COF 专用，只在带真空的单层上训练过，算层间/三维会崩 |
| **MACE-OFF23** | 纯有机体系 | 通用有机势 |

「结构维度」这一项很关键：

- **3D 框架** → 不补真空、输出也不抽真空
- **2D 单层** → 计算时临时补 15 Å 真空（否则镜像被当成成键，整层塌），输出时再抽掉

选「自动判断」时按晶胞形状猜：三维框架三个轴尺度相当，二维的 c 是层间距。
判错的代价很小，但**手动选错会毁结构** —— 把一个 a=b=c=24.7 Å 的立方框架
按 2D 处理，输出的 c 会被压成 21 Å 甚至 18 Å。

优化跑完会：

- 自动显示优化后的结构
- 出一张「优化前后」对比表（a / c / 密度 / 最短间距）
- 提供「下载 CIF」

页面刷新不会丢正在跑的任务，会自动接回来。

#### 层间堆叠能：AA 到底比 AB 稳多少（1.3.1 起）

优化页签最下面有一块「**层间堆叠能**」：给定单层结构，它把两层按
**AA / AB / ABC（或任意分数偏移）** 搭起来，扫一遍层间距 d
（默认 3.0–6.0 Å、步长 0.2），对每个 d 算

    Eb(d) = [E_双层(d) − 2·E_单层] / 每层原子数

取极小就是这种堆法的**层间结合能**（meV/atom，也换算成 meV/Å²），
两种堆法各自取极小后相减，直接告诉你哪种更稳、差多少。

- **d 的定义**：下层最高原子到上层最低原子的 z 间距（最近原子间距），
  3.4–3.6 Å 是化学上合理的 vdW 接触
- 输入如果是界面建出来的多层（`_AA2L.cif` 这种），引擎**自动只取最下面一层**
- 「先弛豫单层」默认开；「最优点再弛豫」默认开 —— 刚体扫描不允许层内
  褶皱/滑移，会明显低估结合能，**报数请用「弛豫后」那一列**
- 势函数务必用 **MACE-MP-0 + D3**：QCOF 是 r_max=4 Å 的短程势，没有
  长程色散，算层间会得到接近 0 甚至正值（界面会弹提示拦一下）
- 结果弹层里是 Eb–d 曲线 + 最优点 + 弛豫后数值表，CSV / JSON 都能下载

实测（LZU-1，MACE-MP-0-medium + D3，RTX CPU）：AA 最优 d≈3.45 Å、
Eb≈−20 meV/atom；AB（半格错位）≈−8 meV/atom；**AA 比 AB 稳约 12 meV/atom**
—— 跟 LZU-1 实验观察到的 AA 堆叠一致。

## 依赖边界

两个环节的依赖差别很大，所以**可以分开指定解释器**：

| 环节 | 需要 | 大概体积 |
|---|---|---|
| 建模 | `numpy` `ase` `rdkit` | 约 100 MB |
| 优化 | `numpy` `ase` `torch` `mace-torch` `torch-dftd` `matplotlib` `scipy` | 1~2 GB |

顶部的「建模」「优化」两个小灯就是这两个环境的健康状态，点开能看到
每个包的具体版本和缺失项。

默认两个环节用同一个解释器（`.venv` 或启动本程序的 Python）。
如果你的 torch 装在另一个环境里，在齿轮图标里把「优化解释器」指过去即可。

### 模型权重

第一次用某个势函数会下载权重，界面上的「允许联网下载」要勾上：

| 模型 | 体积 |
|---|---|
| QCOF | 2.6 MB |
| MACE-OFF23 small / medium / large | 7 / 17.5 / 53 MB |
| MACE-MP-0 medium | 42 MB |

缓存在 `~/.cache/mace/`。

## 分享给别人

整个 `COF_Studio/` 目录打包发过去即可，对方解压后双击 `install.bat`。

**关于 `config.json`**：里面存的是解释器和引擎的路径。如果把自己的配置
一起发出去也没关系 —— 启动时会检查每条路径，指向不存在的会自动清空并
回落到默认值，不会卡住。想干净一点就直接删掉，它会重新生成。

`work/` 里是产物，可以留着当示例，也可以清空。

对方的机器上如果没有 GPU，优化会用 CPU 跑：552 原子、MACE-MP-0-medium
大约 3 秒一步。真跑长任务建议装 CUDA 版 torch：

```bash
pip install torch --index-url https://download.pytorch.org/whl/cu121
```

## 在线更新

exe 里带了一个更新器，**已经装好的人不用重新拷 70 MB**。
更新源**已经预填**，打开「设置 → 版本与更新」点
「检查更新」就能用，不需要配置。

```
https://github.com/1783722112/COF-Studio/releases/latest/download
```

分两级：

- **补丁**（约 150 KB）：`ui.html` + `engines/*.py` + `version.txt`，
  覆盖后刷新页面即生效，不重启；
- **整包**（约 70 MB）：只有改了 `cof_studio.py`（接口、启动逻辑）才需要，
  点「下载整包 → 安装」后程序自己退出、换目录、重启，旧版改名留着可回滚。

更新源不止 GitHub，局域网共享目录、任意静态 HTTP 目录都行，还能填多个
（换行分隔，按顺序试）。发布流程、版本号怎么改、怎么回滚、踩过的坑，
都写在 **[更新发布流程.md](更新发布流程.md)** 里。

## 常见问题

**点「开始建模」报 `ModuleNotFoundError: No module named 'rdkit'`**
建模解释器缺 rdkit。重新跑 `install.bat`，或点开环境面板把「建模解释器」
指到装好 rdkit 的那个 Python。

**优化报「找不到模型」**
勾上「允许联网下载」，或提前把 `.model` 文件放进 `~/.cache/mace/`。

**优化跑着跑着能量飙到 1e17 eV**
多半是把 QCOF 用在多层或三维结构上了。QCOF 只在带真空的单层上训练过，
层间交互没有极小值，一放开晶胞就一路压到互穿。换成 MACE-MP-0 + D3。

**进度条一直停在 0**
阶段 1 是 FIRE 弛豫，每步写进 `work/<名字>_stage1.log`。
界面是从这个文件读步数的，如果一直不动，看控制台有没有报错。

**端口被占用**
换一个：`python cof_studio.py --port 8800`。或者直接运行，它会自动
往后找一个空端口。

## 支持哪些连接方式

2D 页签的「连接方式」下拉里，每一种都自带一对能建通的示例单体（切换下拉
时如果两个输入框是空的，会自动填进去）：

| 连接方式 | 生成的结构 | 典型体系 |
|---|---|---|
| 亚胺 imine | `-CH=N-` | LZU-1、TAPB-PDA |
| β-酮烯胺 | `-NH-CH=C(-C=O)-` | TFP-PDA |
| 烯醇式 | `-CH=N-`（保留酚羟基） | 同上，做对照 |
| 连氮 azine | `-CH=N-N=CH-` | TFB + 肼 |
| 腙 hydrazone | `-CH=N-NH-C(=O)-` | TFB + 对苯二甲酰肼 |
| 烯烃 C=C | `-CH=CH-`（Knoevenagel） | sp2-COF：三醛基三苯苯 + 二甲苯 |
| 氰基烯烃 | `-C(CN)=CH-` | sp2c-COF |
| 酰胺 amide | `-C(=O)-NH-` | 均苯三甲酸 + 对苯二胺 |
| 聚酰亚胺 imide | 五元酰亚胺环（二酐 + 二胺） | PMDA + 三聚氰胺 |
| 芳基–芳基 suzuki | `Ar-Ar`（单键） | 三硼酸苯 + 二溴苯 |

官能团是**自动识别**的：`-CHO`、`-NH2`、`-COOH`、`-B(OH)2`、`Ar-X`、
`Ar-CH3`、`Ar-CH2CN`、酚羟基、酸酐、酰肼都对得上，两个单体的输入顺序无所谓。

### 实测示例（`examples/`）

12 个体系都是用本版本建出来、逐个查过几何的，可以直接拿去做弛豫 / 对照：

| 文件 | 化学式 | a / Å | 最小 sp2 键角 | 说明 |
|---|---|---|---|---|
| `imine.cif` | C36H24N6 | 22.47 | 86.8° | 均苯三甲醛 + 对苯二胺（LZU-1 骨架） |
| `TAPB-PDA.cif` | C72H48N6 | 37.45 | 116.9° | 大孔亚胺 COF，角度最漂亮 |

## 局限（写在这里免得你踩坑）

- 建模用的是**刚体理想化装配**：单体的键长键角取 RDKit 的 3D 嵌入结果，
  两个片段之间用一根刚性连接键拼起来，所以**连接位上的键角会被压弯**
  （理想 120°，实测 87~120°；聚酰亚胺的 N 处最松，约 95°）。
  拓扑、连接数、周期、化学式都是对的，**必须弛豫**才能拿去做 DFT。
  脚本会把「最小 sp2 键角」打出来，低于 90° 会提示。
- 连接位置的氢在装配完成后会**按最终成键几何重摆一遍**（`repair_conn_h`）。
  早先版本里 `=CH-` 的氢会被顶到亚胺氮上（`H···N` 只有 1.06~1.24 Å），
  现在实测 `H···N ≥ 1.7 Å`、`∠H-C-N ≈ 120°`。
- **烯醇式**（保留酚羟基）此前会整层判「不是平面」直接报废：`=CH-` 的氢被
  摆到了垂直于层面的方向（离面 1.06 Å）。原因是补氢的候选方向里"绕层法向
  一圈"用了全局 z、而"上下法向"又没扣分，法向天生没有邻居、最近距离最大，
  于是每次都赢。现在**层内候选优先、法向扣 1.2 Å 分**，只有层内确实站不住
  （氰基烯烃那种）才允许翻出去。12 个示例的重原子离面全部 0.00 Å。
- **氰基烯烃最紧凑**：氰基是接在双键碳上的线形取代基，理想平面排布下
  苯环上的氢会离氰基氮只有 1.5 Å（不算重叠，但很挤）。进势函数
  弛豫时会自动推开；如果想一次到位，把节点换成带长臂的（如 TFPB +
  PDAN，`a = 39.5 Å`）。
- `ctn` 装不下"长臂刚性四面体节点 + 短连接子"的组合（如四苯甲烷四胺 +
  均苯三甲醛），此时脚本会提示改用 `dia`。
- 2D 引擎需要 `cof_builder.py` 和 `build_cof_smiles.py` 在同一个目录。
