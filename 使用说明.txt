COF Studio  ·  COF 建模工作台
======================================================================

【怎么打开】

  双击 COFStudio.exe。

  浏览器内核会弹出一个独立窗口（没有地址栏，看起来就是个普通软件）。
  第一次启动慢一点（2~5 秒，要把内部依赖解出来），之后快。

  想从桌面启动：右键 COFStudio.exe → 发送到 → 桌面快捷方式。
  想卸载：直接删掉整个文件夹，不写注册表、不装东西、不留残留。


【能做什么】

  2D 建模    两个单体 SMILES → 二维 COF 单层（hcb 蜂窝 / sql 方格）
  3D 建模    两个单体 SMILES + 拓扑（ctn / dia）→ 三维 COF 晶胞
  结构预览   拖拽旋转、滚轮缩放、显示/隐藏氢原子、显示晶胞框
  导出       建完就能点「下载 CIF」；结构也可存成 .cif 到 work\ 里

  支持的连接方式（下拉里每一种都自带一对能建通的示例单体）：
     亚胺 / β-酮烯胺 / 烯醇式 / 连氮 / 腙 / 酰胺 / 聚酰亚胺 /
     烯烃 C=C（Knoevenagel）/ 氰基烯烃（sp2c）/ 芳基-芳基（Suzuki）
  官能团自动识别：-CHO、-NH2、-COOH、-B(OH)2、Ar-X、Ar-CH3、
     Ar-CH2CN、酚羟基、酸酐、酰肼；两个单体的输入顺序无所谓。

  界面右上角「中文 / EN」可以切换语言，右上角齿轮里的设置也能改；
  选择存在 config.json 里，下次打开还是这个语言。
  （控制台里引擎打印的诊断信息是中文，那部分不随语言切换。）

  打开后默认停在「2D 建模」页签。


【怎么升级到新版本】

  不用重新拷整包。右上角齿轮 → 「版本与更新」：

    1. 更新源 一般已经填好，不用动：
         https://github.com/1783722112/COF-Studio/releases/latest/download
       想走内网镜像或共享目录，就改成自己的地址；
       多个地址换行分隔，按顺序试，第一个通的就用。
    2. 点「检查更新」。有新版本会露出按钮：
         安装补丁   小改动用这个，几百 KB，刷新页面就生效，不重启
         下载整包   改动大才需要，装的时候会自动重启一次
    3. 装整包时程序会自己退出，几秒后自动起来。
       旧版本改名成 _old_COF Studio_<时间>，下次启动自动清掉。

  想回到旧版本：把 COF Studio 改名，再把 _old_COF Studio_<时间> 改回
  COF Studio 即可。


【这个版本没有打包什么】

  势函数优化（MACE / QCOF）没打进去 —— torch + 权重约 2 GB，塞进来不现实。
  所以"优化"那个页签会显示为不可用。

  如果你的电脑上已经有一个装了 torch / mace-torch 的 Python，
  把它的 python.exe 路径填进同目录的 config.json：

      {
        "py_opt": "C:\\Users\\你\\miniconda3\\envs\\mace\\python.exe"
      }

  改完重启软件，"优化" 就能用了（这是可选步骤，不影响建模）。


【产物在哪】

  COF Studio\work\            建好的 CIF、优化后的 CIF、运行日志
  COF Studio\COFStudio.log    运行日志，出问题先看这个


【常见问题】

  · 双击后弹出"Windows 已保护你的电脑"
      这是 SmartScreen 对"没有数字签名的新程序"的常规拦截，不是病毒。
      点【更多信息】→【仍要运行】即可，之后不再提示。

  · 双击没反应 / 窗口闪一下就没
      说明文件夹被拆开了。_internal 文件夹必须和 COFStudio.exe 待在一起，
      拷贝时整个文件夹一起拷，别只拖 exe。

  · 窗口没自动弹出
      手动打开浏览器访问 http://127.0.0.1:8770

  · 提示端口被占用
      不用管，程序会自动顺延到 8771、8772…

  · 双击两次
      不会开两个服务，第二次会直接把已有窗口调出来。

  · 杀毒软件报警
      PyInstaller 打的包常被误报为可疑程序，加信任即可，没有网络行为。

  · 想看命令行输出 / 指定端口
      cmd 里执行：  COFStudio.exe --port 9000 --no-browser


【技术说明】

  界面是本地网页，后端是 Python 标准库的 http.server，只监听 127.0.0.1，
  不联网。建模计算调用 engines/ 下的四个脚本（随包，源码可读）。

  引擎脚本位于 _internal\engines\，想换成自己改过的版本，
  在 config.json 里把对应路径指过去即可，例如：

      { "engine_build_3d": "D:\\my\\build_cof_3d.py" }
